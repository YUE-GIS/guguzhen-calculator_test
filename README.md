## 用法

1. 点「📋 粘贴」把配置粘进中间框（或直接 Ctrl+V）
2. 左侧选命令、填参数
3. 点「▶ 开始计算」
4. 右侧看中文报告，可切「原始」看计算器原样输出

「? 自检配置」会先跑一次极短测试，确认当前 exe 能读这份配置。

> **提示**：如果自检报 `Error reading NPC enemy data`，说明 exe 版本太旧
> （早期版本不认 `SLIME` 这个野怪名）。换一个新编的 exe 即可。

### al 参数

选中 `al` 时左侧出现专用面板：

- **段位**：C / CC / CCC / B / BB / BBB / A / AA / AAA / S / SS / SSS
- **6 个基础等级**：对应 6 种旧版野怪，1-4000

> 实际测试等级 = `基础等级 × (300 + startlevel) / 300`
> `startlevel` 默认 0。建议在「额外命令」里加 `startlevel 20`，否则容易一路 0% 直接结束。

# 编译

## 依赖

源码用了 `tr1/` 头文件，部分编译器找不到：

```cpp
#include <tr1/unordered_map>
#include <tr1/unordered_set>
```

两种处理：

| 方式 | 做法 |
| --- | --- |
| A | 用 MinGW-w64 GCC（保留 tr1） |
| B | 换成 `<unordered_map>` / `<unordered_set>`，`std::tr1::` 改 `std::` |

方式 B 只改 3 处，语义等价。

## 命令

```bash
# MinGW-w64 GCC
g++ -std=gnu++11 -O2 -pthread -s -o newkf_64.exe newkf.cpp
```

CI 用 GitHub Actions 自动构建（`.github/workflows/build.yml`），产物在 Actions 页面的 artifact 里。

## 自动线程

`THREADS 0` = 按 CPU 核心数自动。Windows 用 `GetSystemInfo`，其他平台用 `sysconf`。

实测 20 核机器（`anpc` + `seedmax 30000` + `tests 2000`）：

| THREADS | 耗时 |
| --- | --- |
| 8 | 3.49 s |
| 20 | 2.26 s |
| 0（自动） | 2.27 s |

# 主要命令

| 命令 | 用途 | 参数 |
| --- | --- | --- |
| `anpc` | 搜索最优属性（打野怪） | 无 |
| `apc` | 搜索最优属性（打玩家） | 无 |
| `bnpc` | 算对野怪胜率 | 无 |
| `bpc` | 算对玩家胜率 | 无 |
| `al` | 按段位算最优收益 | `al <段位> <6个等级>` |
| `b` | 单个敌人胜率 | `b <enemy>` |
| `t` | 单场战斗明细 | `t <enemy>` |
| `rank` | 战力排名 | 无 |

`<enemy>` 三种写法：

```
NPC 0                  配置里的索引
PC 0  或  PC 别名      配置里的索引/别名
SHI 200 0              野怪名 + 等级 + 前缀数(0-4)
```

运行参数（写在配置文件里或命令行输入）：

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| `THREADS` | 线程数 | `0` = 自动 |
| `TESTS` | 每组模拟场次 | 2000（复核用 20000） |
| `SEEDMAX` | 搜索空间 | 30000 |
| `CITEST` | 置信区间阈值 | **保持 0**（开启后慢 5-20 倍） |

配置文件格式、角色/装备/光环数值表，见 b 大计算器原版说明。
